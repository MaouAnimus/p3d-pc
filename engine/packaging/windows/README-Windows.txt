Persona 3: Dancing in Moonlight for PC (p3d-pc)
==============================================

No game files are included. You need your own legitimate copy of Persona 3: Dancing in Moonlight as a folder containing eboot.bin, data (with data.cpk and ps4.cpk), and sce_sys. Tested Title ID: CUSA12636.

Requirements
- Windows 10 (64-bit, 1903 or newer) or Windows 11.
- A 64-bit x86-64 processor. Processors lacking the MOVBE instruction (e.g. AMD Kaveri/Steamroller) run via the included ISA rewrite table without performance penalties.
- A graphics card supporting Vulkan 1.3 with an up-to-date driver.

Starting
1. Extract the game folder under the name "CUSA12636" in the project root.
2. Double-click "p3d_launcher.exe" to adjust display mode, resolution, and controls.
3. Click "PLAY" (or double-click "Jugar.exe" to launch directly with saved settings).

Controls
- Menu / Dialogue: Enter / X / Arrow Down (Cross/A), Backspace / Z (Circle/B), I / Arrow Up (Triangle/Y), E / 3 (R1).
- Rhythm Mode: W/A/S (Up/Left/Down notes), I/L/K (Triangle/Circle/Cross notes), Space / Shift (Scratch/Fever), Escape / P (Pause).
- Controllers: Compatible with Xbox, PlayStation, and generic XInput/DirectInput controllers.

Data & Settings
- Saves: user/savedata/
- Configuration: p3d.ini
- Diagnostic Log: game_last_run.log
